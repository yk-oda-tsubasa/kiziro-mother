# KiCad ローカル引き渡し

KiZiro Mother の回路図と PCB の正式な対応デスクトップ版は KiCad 10.0.8 です。

Windows / Python 3.14。リポジトリ直下から次を実行すると、日本語の選択ダイアログが開きます。

```powershell
py -3.14 tools/kiziro/handoff.py
```

1. KiCad で保存し、プロジェクトを閉じます。「基準 ZIP を作成」で作業フォルダーを選ぶと、隣に `<フォルダー名>-baseline.zip` ができます。この ZIP は比較の基準としてそのまま保管します。
2. Web マネージャーの **Unarchive Project** で基準 ZIP を開きます。その後はデスクトップと Web で別々に編集できます。照合したい時点で Web 側を保存し、**Archive Project** で別の ZIP を作業フォルダーの外に保存します。
3. デスクトップ側も保存して閉じ、ツールを再実行します。「変更を照合」で **現在の作業フォルダー → 基準 ZIP → Web の ZIP** の順に選びます。読み取り中は入力を変更しないでください。
4. 成功すると隣に `<フォルダー名>-candidate` ができます。その中の `.kicad_pro` を KiCad で開いて確認します。元の作業フォルダーを置き換える処理はありません。

CLI でも同じ操作ができます。成功時は出力先を表示し、失敗時は理由を標準エラーに表示して非ゼロで終了します。

```powershell
py -3.14 tools/kiziro/handoff.py snapshot C:\Work\Board
py -3.14 tools/kiziro/handoff.py reconcile C:\Work\Board-baseline.zip C:\Work\Board C:\Downloads\web.zip
py -3.14 -B -m unittest discover -s tools/kiziro -v
```

同名の出力があれば、自動で `-2`、`-3` のように番号を付けます。両コマンドの `-o PATH` で未使用の兄弟パスを指定できます。既存の出力先には書き込みません。処理中の強制終了で残った `.kiziro-work-*` は作業用で、完成した候補ではありません。

比較はファイル単位でSHA-256 を照合します。Web ZIP にない項目は変更なしとして扱います。デスクトップの削除・追加・バイナリ・空ファイルは維持されます。同じ内容への変更はそのまま採用し、同一パスへの異なる変更（削除対編集、異なる内容での新規追加を含む）は競合としてパスを表示します。競合時は候補を作成しません。解決する場合は別の作業コピーで内容を確認・調整してから再照合してください。

ZIP はそれぞれ一つの親フォルダーで包み、その直下に一つだけある `.kicad_pro` のファイル名が三者で完全一致する必要があります。親フォルダー名は一致しなくても構いません。基準 ZIP を作るたびにランダムな 128 ビットのスナップショット ID を発行し、ZIP 内のプロジェクト直下の `kiziro-handoff.json` にだけ保存します。Web ではこのファイルを残してください。両 ZIP の ID が異なる場合やメタデータがない・壊れている場合（旧形式を含む）は候補を作成しません。作業フォルダー直下でこの予約名が使われている場合も停止します。候補にはメタデータを含めません。

ID が示すのは取り込みに使ったスナップショットです。同じ基準 ZIP を複製して始めた Web 作業同士は区別できず、マーカーのコピーや改変に対する真正性の保証もありません。デスクトップ側では、基準と現在の同名ルート回路図の先頭 64 KiB から両方のルート UUID が読める場合だけ、不一致を拒否します。UUID を保った通常の編集は可能です。UUID を引き継いだ複製や、UUID が読めない場合には同名の別作業フォルダーを判別できないので、取り込み元の作業フォルダーを選んでください。

Git 作業フォルダーも選択できます。基準 ZIP と候補には CAD 以外の通常ファイルも含め、`.git` と KiCad の一時ロックファイルは除きます。一時ファイルは作業フォルダーの隣に書き出すため、照合には入力の展開サイズと候補を保存できる空き容量が必要です。リンクや Windows で曖昧なパスは受け付けません。
